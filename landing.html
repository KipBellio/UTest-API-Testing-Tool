What you can do with UTest

1. Send HTTP requests

* Test APIs using GET, POST,
PUT, PATCH, and DELETE methods.

2. View API responses

* Inspect response data, HTTP status
codes, and response timing.

3. Access request history

* Reuse previous requests or delete
them from your saved history.
